# svkit fixture corpus

Every directory here is a small, self-contained **user project**: RTL in `rtl/`, a testbench in
`tb/`, a `Makefile` that works for both flows, a `svkit.toml`, and goldens in `expected/`. All
designs, testbenches, programs and the toy library are original work written for svkit.

Tests never run in this tree. `tests/conftest.py::fixture_copy` copies a fixture **and the sibling
`lib/` directory** into a temp dir, so relative paths like `../lib/svkit_tiny.lib` keep working.
Synthesis runs inside an isolated copy (`.svkit/work/<run>/`) where `../lib` does not exist; svkit
resolves `[library]` paths against the project root, and passes absolute paths to wrapped commands
through `SVKIT_LIBERTY`.

| Fixture | Top / TB | Tests | What it exercises |
|---|---|---|---|
| `counter` | `counter` / `counter_tb` | basic, enable, clear | async reset + sync clear, enable, wrap flag |
| `fifo` | `fifo` / `fifo_tb` | fill_drain, interleave, random | 8x8 sync FIFO, full/empty, overflow/underflow flags, LFSR stimulus |
| `pipe5` | `p5_core` / `p5_tb` | `programs/*.mem` (5) | 5-stage pipeline, forwarding, load-use stalls, branch flushes, CPI counters, **one failing test** |
| `latch` | `latch_hold` / `latch_tb` | basic | an intentionally inferred latch (maps to `DLATCH_*`) |

## Conventions shared by both flows

* **Test selection:** testbenches read `+TEST=<name>` and write `output/<name>.out` (or `.wb`)
  and `output/<name>.vcd` relative to the fixture root. Every output line starts with `@<cycle>`
  so `golden.time_regex = '^@(\d+)'` (`time_unit = "cycle"`) maps a mismatch to a cycle.
* **Clock period:** `clock_period.txt` holds the period in **ps**. The `clock_period` knob is a
  `file` knob writing it; the Makefile exports it as `CLOCK_PERIOD`; the builtin yosys/opensta
  flow reads the knob value directly; the DC template reads the file.
* **Corners:** knob `corner` (`TT` default, `SS`): DC sees it as TCL variable `corner`; the
  open-source flow picks `[library].corners[corner]`.
* **dont_use:** knob `dont_use` (cell globs) is honoured by the builtin yosys flow
  (`dfflibmap`/`abc -dont_use`); the `rvt_only` experiment also carries a `tcl_append`
  `set_dont_use` line for DC.
* **Experiments:** `baseline`, `ss_corner`, `rvt_only`.
* **Synopsys flow:** `synopsys/{syn.tcl,syn_run.tcl,vcs.mk}` are verbatim copies of
  `fixtures/synopsys_common/` (see its README). `make sim-vcs TEST=x` writes `vcs_out/x.log`;
  `make syn-dc` writes `syn_out/<top>.rep`, `.vg`, `.log`. Open-source wrap targets:
  `make sim-verilator TEST=x`, `make syn-yosys` (`syn_out/<top>.stat.json`, `.yosys.v`).

## pipe5 and the T8 ISA

`rtl/p5_pkg.sv` documents the invented 16-bit T8 ISA (8 x 8-bit registers, r0 = 0). Programs are
written in `programs/*.s` and assembled with `make programs` (`tools/t8.py asm`); `tools/t8.py iss`
is a reference instruction-set simulator. `tests/test_oss_parsers.py` checks that every golden
`expected/<prog>.wb` equals the ISS trace once the `@cycle` stamps are removed.

`output/<prog>.cpi` holds `cycles`, `instrs`, `load_use_stalls`, `branch_flushes` (read by
`[perf.source]`).

### The deliberately failing test: `ldst_fwd`

`rtl/p5_hazard.sv` has a **planted bug**: a `ld` immediately followed by a `st` of the loaded
register does not stall, so the store forwards the load's *address* instead of its data.
`programs/ldst_fwd.s` triggers it. Its golden was produced with the bug fixed
(`DEFINES=P5_FIX_LDST_HAZARD`), so the shipped RTL fails with the first divergence at
**line 8, cycle 10**: expected `@11 M[31]=5a`, actual `@10 M[31]=30`. This is the target for
"open a failing test at its divergence". The other four programs pass.

## Toy Liberty library (`lib/`)

`svkit_tiny.lib` (TT) and `svkit_tiny_ss.lib` (SS, 1.3x slower) are generated by
`lib/gen_svkit_tiny.py` (`python3 gen_svkit_tiny.py`; a test checks the committed files match).
Not a real process. `time_unit = 1ns`, caps in fF, leakage in nW, area in um^2. Cells: INV BUF
NAND2 NOR2 AND2 OR2 XOR2 XNOR2 AOI21 OAI21 MUX2 DFF DFFR DLATCH TIEHI TIELO, each as `*_R`
(regular Vt) and `*_L` (low Vt: 0.75x delay, 6x leakage). 2x2 NLDM tables that are exactly linear.

## Known values (open-source flow)

Measured with yosys 0.70 + OpenSTA 2.5.0, TT corner, recorded in
`golden/oss/<fixture>/expected.json` (other tracks assert on these):

| Fixture | T_min (ps) | area (um^2) | cells | WNS @ 2000 ps |
|---|---|---|---|---|
| counter | 241 | 128.5 | 55 | 1759.3 |
| fifo | 387 | 929.5 | 267 | 1613.5 |
| pipe5 | 683 | 2993.0 | 1148 | 1317.4 |
| latch | 50 | 108.0 | 32 | 1950.0 |

T_min = the tightest integer `clock_period` with setup and hold WNS >= 0 (the abc `-D` target
follows the period); pass/fail was monotonic over a 50 ps grid from 50 to 2000 ps.

`golden/oss/{counter,pipe5}/` also hold raw tool output (`stat.json`, `sta_<period>.log`) and the
parsed snapshots (`*.parsed.json`) used by the offline parser tests.
